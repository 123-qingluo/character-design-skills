# Character design_max

> 按人物言行思模式（CBVTM）建模一个角色：先出卡，要深推时再展开，最后能在对话里说人话。
> 集合原型，非指所有个体。不用于临床诊断、真实个体标签化、决定论预测。

## 何时用

- 给小说主角色、剧本 NPC、用户画像建一套**可复跑**的言行模型
- 要解释「他为什么这么拒」，而不只是给一句台词
- 要在多轮对话里保持同一个人

## 何时不用

- 只要一张快速卡、一个单场景推演——按 §六 的快速模式跑即可，不必开深度模块；可用轻问 3 问，赶时间就说「直接出卡」
- 临床判断、给真实个体贴标签——不做

## 一 设计原则


1. **必填轻**：定位、性格三层、言语、好恶、拒绝逻辑、统一公式与参数记录、总结。
2. **深度可选且可触发**：思考逻辑、行为逻辑、四层视角、情景分析按 §6.1 判据开启。
3. **引擎完整**：保留基础循环、三支逻辑、四层视角、跨层结构、情境参数、风格变量。
4. **可检验**：检查清单证据化；示例必须跑清单；参数可复跑。
5. **集合原型**：输出是原型卡，不是对真实个体的诊断或标签化。
6. **参数正交**：情境输入、风格变量、派生量三层分离；情绪拆维；面子不与环境变量并列。
7. **标签必配反例**：每个核心标签配「反例 / 越界条件」；答不出则标签作废或改写。
8. **单一出处**：同一条约束只写一遍，其他位置引用编号。

## 二 核心公式


### 2.1 生成引擎

**人物言行思 = f_G（B 基础循环；T 三支逻辑；V 四层视角；C 跨层结构；P 情境参数；S 风格变量）**

- f_G 是结构性映射，不作数值计算：它只说明卡面字段由哪几组结构共同约束。本 skill 中唯一可数值计算的是拒绝（§2.2）。
- B、T、V、C 的定义见 §4；P、S 的定义与档位见 §3。
- **输出卡面** = 上述引擎在「定位、性格三层、言语库、好恶、拒绝逻辑、可选深度模块、参数记录、标签—反例对」上的投影。

### 2.2 拒绝公式

**拒绝 = f_R（P；S）→ 派生 F/C/G（§3.3）→ 策略档（§3.4）→ 语用编码（§3.5）→ 补偿档（§3.7）→ 言语行为 → 听者解码 / 反馈 → 关系重构**

先判「接受 / 拒绝」：按 §3.4 的接受判定，`q_l ≥ 0 且 A ≤ C` 时直接接受，不进入上式，也不填拒绝逻辑。

注意：「性格、言语、好恶」是输出卡面，不是引擎参数。统一公式不得写成「人物 = f（性格，言语，好恶，拒绝逻辑，情境参数，风格变量）」，那会丢掉四层视角与跨层结构。

## 三 参数体系（唯一定义处）


### 3.1 情境输入 P（12 项，两两正交）

| 代号 | 参数 | 取值域 | 说明 |
| --- | --- | --- | --- |
| r | 关系 | −1 敌对；0 陌生；1 弱关系；2 熟识；3 亲密 | 决定给不给面子、留不留后路 |
| p | 权力差 | 0 平权；1 微差；2 明显；3 强制 | 对方相对角色的权力，即对方能压住角色的程度 |
| o | 公开度 | 0 私下；1 半公开；2 公开 | 情境事实，不含角色感受 |
| w | 观众重要性 | 0 无；1 低；2 中；3 高 | 与 o 正交：公开但无重要观众 w=0；私下但关键一人在场 w 可高 |
| q_s | 请求大小 | 0 无；1 小；2 中；3 大 | 执行成本 |
| q_l | 请求合理性 | −1 越界；0 模糊；+1 合理 | 越界 + 不可撤回，硬拒绝概率上升 |
| q_r | 可撤回性 | 0 可撤回；1 不可撤回 | 同上 |
| i | 利益 / 资源 | −2 大损；−1 小损；0 中性；+1 小利；+2 大利 | 相对角色而言 |
| c | 麻烦度 | 0 无；1 小；2 中；3 大 | 决定借口强度 |
| e_v | 情绪效价 | −2 强负；−1 负；0 平；+1 正；+2 强正 | 只记效价 |
| e_a | 情绪唤醒 | 0 低；1 中；2 高；3 极高 | 与 e_v 正交 |
| e_t | 具体情绪 | 焦虑 / 羞耻 / 内疚 / 愤怒 / 愉悦 / 亲近，各 0—3，可多选 | 不由 e_v、e_a 反推 |

### 3.2 风格变量 S（角色常量，0—3）

| 代号 | 变量 | 刻度 | 用途 |
| --- | --- | --- | --- |
| s_f | 面子敏感 | 0—3 | 进 F |
| s_g | 内疚敏感 | 0—3 | 进 G |
| s_d | 直接性 | 0—3 | 进 §3.4 兜底规则 |
| s_n | 亲密需求 | 0—3 | 进 §3.4 规则 1（特殊拒绝门槛） |
| s_def | 防御强度 | 0—3 | 进 §3.5 编码偏好 |
| code | 语码 | 兄弟 / 恋爱 / 权威 / 线上 / 陌生人 | 只进言语库，不进判据 |

### 3.3 派生量 F / C / G 与计算式

算法分三步：各分项先归到 0—3 → 算术平均 → 取整并 clamp 到 0—3。

**数值约定**（全文适用）：

- clamp(x) = min(3, max(0, x))，边界含 0 与 3。
- round 一律四舍五入，**.5 进位**（round half up），不得使用银行家舍入；本文档出现的 round 均按此口径。
- 分项代入前先 clamp 到 0—3，尤其是 i′ 与越界加码 b。
- max(0, r) 表示敌对关系按 0 折算，不产生负的亲密贡献。
- 结果一律取整，不保留小数，便于 §3.6 复跑比对。

| 派生量 | 含义 | 计算式 | 范围 |
| --- | --- | --- | --- |
| F 面子风险 | 当众拒绝要付的社交代价 | F = clamp(round((o + w + s_f + q_s + b) / 4))；b 为越界加码，q_l = −1 记 2、0 记 1、+1 记 0 | 0—3 |
| C 拒绝成本 | 拒绝要付的权力与关系代价 | C = clamp(round((p + max(0,r) + i′ + F) / 4))；i′ = clamp(i + 2) | 0—3 |
| G 内疚预期 | 拒绝后的自责强度 | G = clamp(round((max(0,r) + (q_l + 1) + s_g) / 3)) | 0—3 |
| A 接受成本 | 接受这件事对角色有多难受 | A = clamp(round((c + (3 − i′)) / 2))；i′ 见 C 的计算式 | 0—3 |

A 与 C 构成一组对照：C 是「拒绝要付的代价」，A 是「接受要付的代价」。**C 用来选拒绝档位，A 只用来判定该不该拒**（见 §3.4）。

校准样例（同一角色：s_f=3、s_g=1、s_d=1、s_n=2）：

| 情境 | 关键输入 | F | C | G | A | 判定 |
| --- | --- | --- | --- | --- | --- | --- |
| 兄弟当众要我替他代练（越界、可撤回） | r=3 p=0 o=2 w=2 q_s=2 q_l=−1 q_r=0 i=−1 c=2 | 3 | 2 | 1 | 2 | q_l 越界 → 不接受；F=3 → 软拒绝 |
| 喜欢的人公开邀约，兄弟在场 | r=2 p=1 o=2 w=2 q_s=1 q_l=+1 q_r=0 i=+2 c=1 | 2 | 2 | 2 | 1 | 成本上可接受（A=1 ≤ C=2）；**但本表不含 e_t**，羞耻≥2 时规则 1 先命中 → 特殊拒绝，见 §9.4 |
| 导师私下让我周末改稿（合理、不可撤回） | r=1 p=3 o=1 w=1 q_s=3 q_l=+1 q_r=1 i=+1 c=3 | 2 | 2 | 1 | 2 | A=2 ≤ C=2 且不越界 → 接受 |

**本表只算成本，不含 `e_t`。** 规则 1 要 `羞耻 ≥ 2`，凡涉及亲近场景的判定都必须补 `e_t` 再定档——§9.4 是同一情境的完整版。

### 3.4 策略档判定（按序匹配，首个命中即停）

| 序 | 条件 | 结果 |
| --- | --- | --- |
| 1 | r ≥ 2 且 e_t 亲近 ≥ 2 且 e_t 羞耻 ≥ 2 且 s_n ≥ 2 | 特殊拒绝（嘴硬心软） |
| **接受判定** | **q_l ≥ 0 且 A ≤ C** | **接受，不进入拒绝链，不填拒绝逻辑** |
| 2 | q_l = −1 且 q_r = 1 且 C ≤ 1 | 硬拒绝 |
| 3 | F ≥ 2 或 G ≥ 2 | 软拒绝 |
| 4 | C = 0 且 G = 0 | 硬拒绝（低内疚变体，不新增档名） |
| 5 | 兜底：s_d ≥ 2 → 硬拒绝；s_f ≥ 2 或 s_g ≥ 2 → 软拒绝；否则 F > G 取硬、G ≥ F 取软 | 按结果 |

**仲裁规则**：只取首个命中的行，不得多档并列；表格自上而下匹配，命中即停。

**两条硬约束**：

- 规则 1 排在成本比较之前，因为亲密场景里的「说不」常常不划算——它是**非理性否决层**，不能被 A/C 比较掉。
- q_l = −1（越界）一律不适用接受判定：有好处也不能答应越界的请求。

**偏离处理**：规则是启发式，不是决定论预测。若实际推演偏离规则，须写明是哪一步（内部言语 / 元认知）改变了策略。

### 3.5 编码偏好（s_def 的用途）

| s_def | 编码方式 | 例 |
| --- | --- | --- |
| 0—1 | 直述型 | 说事实、给理由 |
| 2 | 缓冲型 | 先共情、再拒绝、给替代方案 |
| 3 | 回避型 | 拖延回复、沉默、幽默化解、拉黑 |

编码方式由 s_def 定档，具体话术仍受 §5 链约束。

### 3.6 回归测试

同一角色、同一 P/S 跑两次，§3.4 输出的档位应一致；不一致须记录偏离步骤与偏离原因。深度模式必须记录全部 P/S 档位与 F/C/G/A，且用 §3.3 计算式重算应得同值。

### 3.7 补偿档 K（拒完的补偿驱动）

拒绝会同时伤对方的面子与本方的自我形象。补偿量由内疚决定，**不由礼貌程度决定**——过分客气的补偿是掩饰，不是修复。

| K | 条件 | 要求 |
| --- | --- | --- |
| 0 | G ≤ 1 | 至多一项补偿，且不得用关系补偿（感谢/示好）充数 |
| 1 | G = 2 | 至少一项补偿 |
| 2 | G = 3 | 至少两项补偿，且必须含「替代」或「事后」之一（实质补偿，不能只有客套） |

两条修饰（覆盖上表）：

- **硬拒绝 → K 封顶 1**：设边界的人不大补偿，补偿过重会让边界失效。
- **特殊拒绝 → K 固定为 2**，且必须是**行为补偿**（做出来的，不是嘴上说的）。

补偿四类：

| 类 | 内容 | 例 |
| --- | --- | --- |
| 理由 | 解释为什么不 | 「这周排班满了」 |
| 替代 | 给另一条路 | 「走廊尽头那个位置给你」 |
| 关系 | 感谢 / 肯定 / 示好 | 「谢谢你想到我」 |
| 事后 | 承诺下次 / 事后再来 | 「下周我替你跟一次」 |

**联动**：K ≥ 1 → §5 第 9 步的关系重构偏向「修复」；K = 0 → 偏向「降级 / 疏远」。补偿档是重构方向的前置判据，不是事后装饰。

## 四 理论骨架（唯一定义处）


### 4.1 基础循环（9 步）

情境 / 他者 → 知觉评估 → 情绪动机 → 内部言语 / 推理 → 元认知 / 语用预演 → 意图 → 言行 → 反馈 → 重构

### 4.2 三支逻辑

- **思考逻辑**：内化社会对话 → 内部言语 → 推理 / 元认知 → 自我调节。
- **言语逻辑**：意图 → 语境 / 面子 / 权力 → 语用编码 → 言语行为 → 听者解码 → 反馈。拒绝场景统一调用 §5。
- **行为逻辑**：目标 / 习惯 / 规范 → 手段 → 行动 → 强化 / 惩罚 → 调整。

### 4.3 四层视角

个体内部、他人、大他者 / 象征秩序、社会文化。术语见附录 A。

### 4.4 跨层结构

生物—心理—社会—语言—文化—历史。

写法：六层名单固定（生物—心理—社会—语言—文化—历史）。**至少写到 3 层各 1 句**，每层一句「约束 / 资源 / 风险」；**全开模式六层写满**。快速模式不写跨层。

## 五 唯一拒绝链（9 步，与 §4.1 逐格对齐）


1. 请求 / 邀请 / 命令（情境）
2. 知觉评估：读 §3.1 的 r、p、o、w、q_s、q_l、q_r、i、c 与 §3.2 的 S，在同一节点内按 §3.3 算出 F / C / G
3. 情绪动机：焦虑、内疚、羞耻、烦躁、亲近、恐惧
4. 内部言语 / 推理：值不值、得不得罪、有没有后路
5. 元认知 / 语用预演：对方会怎么解码、关系会怎么反馈
6. 拒绝意图：按 §3.4 选档
7. 语用编码与言语行为：编码方式按 §3.5（借口、道歉、梗、直接否定、沉默、拉黑），补偿按 §3.7 的 K 档落到位
8. 听者解码 / 反馈
9. 关系重构：修复 / 降级 / 设边界 / 疏远（方向由 §3.7 的 K 档决定）

**档位样例**：软拒绝「我有课，可能晚点」；硬拒绝「不去，这次不安排」；特殊拒绝「谁要跟你去」，但偷偷到场。

**一致性**：9 步与 §4.1 逐格对应，不得省「情绪动机」与「重构」。§4.2 言语支、§6.2 步骤 6 只引用本条。派生量已并入第 2 步，不单列一步，故仍为 9 步。

## 六 模式判据与操作步骤（唯一定义处）


### 6.0 设计前提问（对齐访谈，唯一定义处）

**目的**：在出卡前把使用者预期落成可写进卡面的决策；模型不静默补全，也不把访谈带进运行层。

**适用**：所有建模模式先走本节；用户明确说「直接出卡」「不用问」时跳过，并在 brief 标注假设。

#### 6.0.1 三条纪律

1. **只问决策，不问参数**：不要求用户填 P / S 数值；模型从叙事答案推断，并在 brief 展示。
2. **只问会改变卡面的问题**：能由原型、场景或既有设定推出的，不问；不改变标签、拒绝逻辑、补偿或运行声音的，不问。
3. **每问必带推荐答案**：格式为「问题 + 我猜的答案」；用户可确认、改写或说「都按推荐」。

例：「角色最怕被谁看见什么？我猜：最怕被同班男生看见自己主动；你不改，我就按这个写。」

#### 6.0.2 提问档位与预算

**第 0 问（模式选择，不计入问题预算）**

这次用哪档对齐？

- A 轻问：1 轮 3 问；推荐一次性配角、单场景、上下文紧。
- B 标准：2 轮 6 问；推荐主要配角、短篇主角、需要稳定拒绝逻辑。
- C 深问：3 轮最多 9 问；推荐长篇小说主角色、核心 NPC、全开。

➡️ 推荐：用途不明确时默认 A；用户明确说长篇 / 核心角色 / 全开时推荐 C。  
模式只决定提问轮数，不决定建模模式；快速卡 / 深度 / 全开仍按 §6.1。

| 档位 | 轮次 | 问题数 | 适用 |
| --- | --- | --- | --- |
| 轻问 | 1 轮 | 3 问 | 一次性配角、单场景、上下文紧 |
| 标准 | 2 轮 | 6 问 | 主要配角、短篇主角、需要稳定拒绝逻辑 |
| 深问 | 3 轮 | 最多 9 问 | 长篇小说主角色、核心 NPC、全开 |

- 模式选择不计入 3 / 6 / 9 的问题预算。
- 用户未选模式时按轻问；可升级一次（轻→标准→深），已答内容问题保留，不重复问。
- 不跨档追加问题；到预算即停。用户说「继续问」可加一轮，但须说明新增问题会改变哪一项卡面。
- 每轮只问当前可问的前沿：前置决策已定的问题；下一轮再问依赖答案的问题。
- 「快速卡」只表示输出预算，不自动跳过提问；跳过须明确说「直接出卡 / 不用问」。

#### 6.0.3 提问树与问题库

按以下顺序展开，不跳层：

```text
用途 / 篇幅
  → 核心矛盾
    → 标签与反例
      → 拒绝逻辑
        → 补偿 / 运行时声音
```

以下 Q1—Q9 为内容问题，不含第 0 问的模式选择。

**轻问 3 问**：
1. 角色最怕被谁看见什么？
2. 什么情况下角色一定破功？
3. 角色绝不会说哪句话？

**标准第 2 轮加问**：
4. 谁让角色嘴硬？谁让角色不用嘴硬？
5. 故事里最坏的结果是什么？角色宁可被误解也不愿做什么？
6. 角色拒绝时最常用 / 最不会用哪种方式？

**深问第 3 轮加问**：
7. 过去谁放过角色鸽子，或什么经历让角色形成这条规则？
8. 学校 / 家庭 / 同伴舆论怎么看角色？
9. 角色所在的文化脚本（性别、成绩、社团）给角色什么压力？

问题要问「角色会怎么做」，不要问「你希望角色多可爱」。前者得到角色逻辑，后者得到偏好拼贴。

#### 6.0.4 对齐 brief（出卡前确认）

答完当前轮次后，先给 brief，不直接出卡：

| 项 | 内容 |
| --- | --- |
| 访谈档位 | 第 0 问所选：轻问 / 标准 / 深问；未选则写「默认轻问」 |
| 用途 / 篇幅 | ... |
| 已定 | 用户确认的原话或改写；至少覆盖核心矛盾、一个破功点、一条拒绝 / 补偿行为 |
| 我推断的 | 标签、P / S 档位、F / C / G / A、可能的深度模块；标明「推断」 |
| 未定 / 风险 | 还没问到的、互相冲突的、需要作者拍板的 |
| 本轮不答则按假设处理 | 具体假设；不得静默补全 |

用户确认 brief 后再出卡；用户只改 brief 时，先改 brief，不先改卡。

#### 6.0.5 冲突、停止与运行隔离

- **冲突**：两个答案互斥时，指出冲突，给两个可选解法，只问一个问题；不得取平均或静默选一个。
- **停止**：用户说「直接出卡 / 不用问」；预算用完；答案已不再改变卡面；三者任一即停。
- **运行隔离**：卡确认后提问关闭。运行层只输出角色言行，不提问、不复述 brief、不解释「我是怎么设计的」；需要修复时按 references/runtime.md §11 执行。

### 6.1 模式判据

**快速模式（默认）**：执行 §6.2 步骤 1—6 + 步骤 11（参数记录）+ 总结。

步骤 0（§6.0）先于所有模式执行；用户明确跳过时按 §6.0.5 处理。

硬性要求：步骤 6 的拒绝逻辑须含至少一条「言行 → 听者解码 → 关系重构」，以满足 references/checklist.md §8 A 表第 5 项；参数记录至少填拒绝相关 P 档位与 s_f / s_g / s_d，以满足 A 表第 9 项。

**深度模式**：按模块开启，不必全开。

| 模块 | 开启判据 | 最小产出 | 对应检查项 |
| --- | --- | --- | --- |
| 思考逻辑 | 需解释「想一套说一套」、内心戏、独白、防御机制 | 评估 → 内部言语 → 元认知 → 防御 → 实践三段论 → 公式 | A6a |
| 行为逻辑 | 角色对 ≥3 类对象行为不同，或需写权威 / 线上差异 | 对 A / 对 B / 对权威 / 线上各 1 条 + 链 | A6b |
| 四层视角 | 冲突涉及规范、羞耻、身份、社会文化压力 | 四层各 1—2 行；跨层 ≥3 层各 1 句（全开时六层写满） | A6c |
| 情景分析 | 需预测一次完整「请求 → 反馈 → 重构」或多轮冲突 | 完整 9 步 + P 档位 + F / C / G | A6d |
| 全开 | 长篇小说主角色、游戏 NPC 核心、冲突推演、用户明确要求 | A6a—A6d 全做 | A6a—A6d |

**限制**：非全开时按优先级选，最多开 2 个：情景分析 > 四层视角 > 行为逻辑 > 思考逻辑。

### 6.2 操作步骤（0 + 12 步）

0. 对齐访谈：先按 §6.0.2 问模式（轻问 / 标准 / 深问），再按该档提问并确认 brief；用户明确跳过时，在 brief 标注假设。
1. 定原型：年龄、身份、核心标签（1—3 个，每个配反例 / 越界）、一句话定位
2. 定冲突：接近—回避、自尊、面子、权力、欲望、焦虑
3. 分三层：表层 / 中层 / 深层；深层能解释表层，中层不打架
4. 建言语库：对谁、语码、口头禅、梗、表情包
5. 列好恶
6. 写拒绝逻辑：调用 §5，填软 / 硬 / 特殊拒绝，附至少一条反馈 / 重构
7. 可选：写思考逻辑（按 §6.1 判据）
8. 可选：写行为逻辑（按 §6.1 判据）
9. 可选：嵌四层视角与跨层结构（按 §6.1 判据）
10. 可选：参数化情景推演（按 §6.1 判据）
11. 统一公式与参数记录：填 §3 档位、按 §3.3 算 F / C / G、记语码
12. 自检：按 references/checklist.md §8 先过 C 表（用户对齐），再过 A 表（卡面质量）；不通过返工

## 十 一句话总结


CBVTM = 用生成引擎保证深度，用轻量卡面保证可用；规则单一出处，参数正交可复跑，标签必配反例，拒绝链唯一，示例必须自检；判定先分「接不接受」（A vs C），再分「怎么拒」（规则 1—5），拒完按 K 档补偿；建模一次、运行每轮——对话里出的是人话，不是卡。
