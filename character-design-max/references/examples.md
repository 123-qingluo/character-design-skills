## 九 示例与示例自检（示例不定义规则）


### 9.1 快速卡：普通男大学生

- **一句话定位**：大二男生，靠「兄弟局话痨、恋爱局怂包」维持面子，卡在装酷与真怂之间。
- **核心定位**：20 岁大二男生。核心标签与反例：
  1. 嘴硬装酷；反例 / 越界：喜欢的人当众求助且兄弟不在场时，会直接帮忙，不嘴硬。
  2. 兄弟局话痨；反例 / 越界：兄弟当众揭短时突然沉默。
  3. 恋爱局怂包；反例 / 越界：对方私下明确表白且无观众时，反而能直接回应。
- **性格三层**：表层装酷、嘴硬、爱接梗；中层有限理性，知道该学习但总拖；深层焦虑怕丢脸，怕被看穿不自信。核心冲突：装酷 vs 真怂；兄弟局 vs 恋爱；游戏 vs 绩点。
- **言语库**：对兄弟话多损友式；对喜欢的人短句、回避、故作冷淡；对权威表面服从。口头禅「都行」「随便」「这不废话吗」。语码：兄弟 / 恋爱 / 权威 / 线上。
- **好恶**：喜欢游戏、兄弟夜聊、被认可；厌恶当众出丑、被催绩点、被看穿怂。
- **拒绝逻辑**：软拒绝「我有课 / 我有事，可能晚点」；硬拒绝「不去，这次不安排」；特殊拒绝「谁要跟你去」，但会偷偷到场，并带上对方爱喝的那款奶茶。
- **反馈 / 重构**：兄弟解码为「他就这样」，关系维持；喜欢的人解码为「嘴硬」，关系半信半疑，角色下次更回避。
- **统一公式与参数记录**：
  - P（典型情景）：r=2；p=1；o=2；w=2；q_s=1；q_l=+1；q_r=0；i=+2；c=1；e_v=+1；e_a=2；e_t 焦虑 2 / 羞耻 2 / 亲近 2。
  - S：s_f=3；s_g=1；s_d=1；s_n=2；s_def=2；code=兄弟 / 恋爱 / 权威 / 线上。
  - 派生：按 §3.3 算得 F=2，C=2，G=2，A=1；规则 1 先命中，策略档 = **特殊拒绝**；按 §3.7 特殊拒绝 → **K=2**：两项补偿，均为行为型（事后到场 + 关系补偿带奶茶）。
- **一句话总结**：表面嘴硬装酷，内里怕丢脸；兄弟局放开，恋爱局退缩。

### 9.2 深度示例：同一角色（按 §6.1 的**全开许可**开启全部四项——长篇小说主角色）

**6a 思考逻辑**

- 评估：先扫「谁在场、会不会丢脸、能否撤退」。
- 内部言语：「不去显得怂；去了更怂；先找个理由。」
- 元认知：预演对方反应；若可能被看穿，则加倍嘴硬。
- 防御：幽默化、回避、合理化「我有课」。
- 实践三段论：大前提「兄弟面前不能露怂」；小前提「她公开邀我且兄弟在场」；结论「先嘴硬软拒，再偷偷补偿」。
- 公式：思考 = f（s_f=3，s_n=2，s_def=2，o=2，w=2）→ 先防御后补偿。

**6b 行为逻辑**

- 对兄弟：主动组局、话多、损友式。
- 对喜欢的人：短句、回避、故作冷淡，但会偷偷到场。
- 对权威：表面服从、拖延执行。
- 线上：群聊活跃；对喜欢的人私聊延迟回复。
- 链：目标保面子 → 手段嘴硬 / 找借口 → 行动拒绝 → 强化（兄弟认同）→ 调整（对喜欢的人改为补偿）。

**6c 四层视角与跨层约束**

- 个体内部：怕丢脸，怕被看穿不自信。
- 他人：兄弟看作「嘴硬但靠谱」；喜欢的人看作「忽冷忽热」。
- 大他者 / 象征秩序：男性「酷 / 不主动」脚本、绩点规范。
- 社会文化：大学兄弟文化、恋爱主动性脚本、拖延亚文化。
- 跨层：生物—睡眠不足降低忍耐；心理—羞耻敏感；社会—兄弟起哄压力；语言—损友语码；文化—男性不主动脚本；历史—高中被嘲经历。

**6d 情景分析**

- 请求：喜欢的人公开邀约周末自习，兄弟在场。
- 评估：r=2；p=1；o=2；w=2；q_s=1；q_l=+1；q_r=0；i=+2；c=1；e_v=+1；e_a=2；e_t 焦虑 2 / 羞耻 2 / 亲近 2。派生 F=2；C=2；G=2。按 §3.4 规则 1 命中 → 特殊拒绝。
- 情绪动机：羞耻 + 亲近。
- 内部言语：「答应像舔，不答应像怂。」
- 元认知预演：预演被兄弟起哄。
- 意图：特殊拒绝，事后补偿。
- 言行：软拒「我有课，可能晚点」，私聊问「你们几点走」，到场装偶遇。
- 反馈：对方解码为嘴硬；兄弟起哄强化。
- 重构：对方半信半疑，角色下次更回避。

**尺度判据**：四层视角写 3—5 行即可；跨层每层一句；情景分析跑一次完整链即可；不必写三页。

### 9.4 接受示例：同一角色（验证 §3.4 的接受判定）

- **情境**：凌晨四点，周哲说「明天中午我请你吃火锅，就当赔罪」。
- **评估**：r=3；p=0；o=0；w=0；q_s=1；q_l=+1；q_r=0；i=+2；c=1；e_t 亲近 3 / 羞耻 0。
- **派生**：F=round((0+0+3+1+0)/4)=**1**；C=round((0+3+3+1)/4)=**2**；G=round((3+2+1)/3)=**2**；A=round((1+0)/2)=**1**。
- **判定**：规则 1？亲近 3 ✔ 但羞耻 0 → 不中。接受判定？q_l = +1 ≥ 0 ✔ 且 A=1 ≤ C=2 ✔ → **接受**。
- **输出**：不填拒绝逻辑，不判 K 档（K 只服务拒绝）。话术「行啊，但我只吃辣的」，关系动作：把手机放下，靠回墙边。
- **对照**：同一角色、同一关系，换请求就换结局，三条路各由不同机制决定：
  - 兄弟在场时被喜欢的人公开邀约（§9.1，亲近 2 / 羞耻 2，i=+2）：规则 1 命中 → **特殊拒绝**。此时 A=1 ≤ C=2，只看成本应当接受；规则 1 压过成本比较，这是非理性否决层。
  - 凌晨四点周哲请吃火锅（羞耻 0，i=+2）：规则 1 因羞耻 0 不中 → 接受判定 A=1 ≤ C=2 成立 → **接受**。
  - 同一关系下改成周哲来借钱（羞耻 0，i=−2）：i′=0，C=round((0+3+0+1)/4)=**1**、A=round((1+3)/2)=**2**，A ≤ C 不成立 → 落规则 3（G=2）**软拒绝**，K=1。
  - 反差的关键在于 **C 随 i′ 同向、A 随 i′ 反向**：i 从 +2 掉到 −2 时 C 降、A 升，接受判定失效。
