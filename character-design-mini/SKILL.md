# Character design_mini

> CBVTM 的轻量版：一个原型 + 一个情境 → 一张快速卡 + 一次言行推演。
> 集合原型，非指所有个体。不用于临床诊断、真实个体标签化、决定论预测。

## 何时用

- 一次性出角色卡：小说设定、人物档案、用户画像
- 单场景推演：给定请求，推他会怎么拒、拒完怎么补
- 上下文紧，或要同时处理多个角色

## 何时不用

- 要四层视角、跨层六层、思考逻辑或行为逻辑的深推——这些模块**默认不启用**；按 §五 判据可开启，但只有最小产出、没有示范，容易写成空壳
- 长篇多轮扮演——本文件只带最小运行时，状态靠人盯

## 一 输入与输出


| 项 | 内容 |
| --- | --- |
| 最小输入 | 角色原型（年龄或身份，一句话）+ 使用场景（小说 / 游戏 / 社交推演 / 话术） |
| 缺项处理 | 先写「假设：……」再出卡，不得静默补全 |
| 产出预算 | 快速卡 ≤ 600 字；单模块 ≤ 1200 字；全开 ≤ 2000 字。超预算先删例证，不删判据 |
| 输出形态 | **对话模式默认不输出卡面与参数**，只出角色言行；用户明确要卡时才出卡，并附 references/runtime.md §9.1 的运行时档案 |

## 二 参数（唯一定义，其余章节只引用）


**生成引擎**：人物言行思 = f_G（B 基础循环；T 三支逻辑；V 四层视角；C 跨层结构；P 情境参数；S 风格变量）。f_G 是结构性映射，不作数值计算；本 skill 唯一可算的是 §3.1 的派生量。卡面是引擎在 §六 各字段上的投影。

### 2.1 情境输入 P（12 项，两两正交）

| 代号 | 参数 | 取值 |
| --- | --- | --- |
| r | 关系 | −1 敌对；0 陌生；1 弱；2 熟识；3 亲密 |
| p | 权力差 | 0 平权；1 微差；2 明显；3 强制（对方能压住角色的程度） |
| o | 公开度 | 0 私下；1 半公开；2 公开 |
| w | 观众重要性 | 0 无；1 低；2 中；3 高（与 o 正交：公开但无重要观众 w=0） |
| q_s | 请求大小 | 0 无；1 小；2 中；3 大 |
| q_l | 请求合理性 | −1 越界；0 模糊；+1 合理 |
| q_r | 可撤回性 | 0 可撤回；1 不可撤回 |
| i | 利益 / 资源 | −2 大损；−1 小损；0 中性；+1 小利；+2 大利（相对角色） |
| c | 麻烦度 | 0 无；1 小；2 中；3 大 |
| e_v | 情绪效价 | −2 强负；−1 负；0 平；+1 正；+2 强正 |
| e_a | 情绪唤醒 | 0 低；1 中；2 高；3 极高（与 e_v 正交） |
| e_t | 具体情绪 | 焦虑 / 羞耻 / 内疚 / 愤怒 / 愉悦 / 亲近，各 0—3，可多选；不由 e_v、e_a 反推 |

### 2.2 风格变量 S（角色常量，0—3）

| 代号 | 变量 | 用途 |
| --- | --- | --- |
| s_f | 面子敏感 | 进 F |
| s_g | 内疚敏感 | 进 G |
| s_d | 直接性 | 进兜底规则 |
| s_n | 亲密需求 | 进特殊拒绝门槛 |
| s_def | 防御强度 | 决定编码方式 |
| code | 语码 | 兄弟 / 恋爱 / 权威 / 线上 / 陌生人；只进言语库，不进判据 |

### 2.3 数值约定

clamp(x) = min(3, max(0, x))；round 四舍五入且 **.5 进位**（不用银行家舍入）；分项先 clamp 再代入；结果一律取整。

## 三 派生量与判定


### 3.1 派生量（由 P、S 算出，不单列为输入）

| 量 | 含义 | 计算式 | 范围 |
| --- | --- | --- | --- |
| F | 面子风险：当众拒绝要付的社交代价 | F = clamp(round((o + w + s_f + q_s + b) / 4))，b 为越界加码：q_l=−1 记 2、0 记 1、+1 记 0 | 0—3 |
| C | 拒绝成本：拒绝要付的权力与关系代价 | C = clamp(round((p + max(0,r) + i′ + F) / 4))，i′ = clamp(i+2) | 0—3 |
| G | 内疚预期：拒绝后的自责强度 | G = clamp(round((max(0,r) + (q_l+1) + s_g) / 3)) | 0—3 |
| A | 接受成本：接受这件事有多难受 | A = clamp(round((c + (3 − i′)) / 2))；i′ 见 C 行 | 0—3 |

C 与 A 是一组对照：C 决定**怎么拒**，A 只决定**该不该拒**。

### 3.2 判定顺序（自上而下，命中即停）

| 序 | 结果 | 条件 |
| --- | --- | --- |
| 1 | 特殊拒绝（嘴硬心软） | r ≥ 2 且 e_t 亲近 ≥ 2 且 e_t 羞耻 ≥ 2 且 s_n ≥ 2 |
| — | **接受**（不填拒绝逻辑） | **q_l ≥ 0 且 A ≤ C** |
| 2 | 硬拒绝 | q_l = −1 且 q_r = 1 且 C ≤ 1 |
| 3 | 软拒绝 | F ≥ 2 或 G ≥ 2 |
| 4 | 硬拒绝（低内疚变体） | C = 0 且 G = 0 |
| 5 | 兜底 | s_d ≥ 2 → 硬；s_f ≥ 2 或 s_g ≥ 2 → 软；否则 F > G 取硬、G ≥ F 取软 |

两条硬约束：

- 规则 1 排在成本比较之前。亲密场景里的「说不」常常不划算，它是**非理性否决层**。
- q_l = −1 一律不适用接受判定：有好处也不能答应越界的请求。

### 3.3 补偿档 K（拒完之后）

补偿量由内疚决定，不由礼貌决定。

| K | 条件 | 要求 |
| --- | --- | --- |
| 0 | G ≤ 1 | 至多一项，且不得用关系补偿（感谢 / 示好）充数 |
| 1 | G = 2 | 至少一项 |
| 2 | G = 3 | 至少两项，且必须含「替代」或「事后」之一 |

修饰：**硬拒绝封顶 1**（补过头边界就没了）；**特殊拒绝固定 2 且须为行为补偿**（做出来的，不是嘴上说的）。

补偿四类：理由（解释为什么不）／替代（给另一条路）／关系（感谢、肯定）／事后（承诺下次）。

联动：K ≥ 1 → 第 9 步重构偏向「修复」；K = 0 → 偏向「降级 / 疏远」。

### 3.4 编码偏好（s_def）

| s_def | 方式 | 例 |
| --- | --- | --- |
| 0—1 | 直述 | 说事实、给理由 |
| 2 | 缓冲 | 先共情、再拒绝、给替代 |
| 3 | 回避 | 拖延回复、沉默、幽默化解、拉黑 |

## 四 链条（9 步）


基础循环：情境 / 他者 → 知觉评估 → 情绪动机 → 内部言语 → 元认知预演 → 意图 → 言行 → 反馈 → 重构。

拒绝链是它在拒绝场景的实例，同为 9 步：

1. 请求 / 邀请 / 命令
2. 知觉评估：填 §2.1 与 §2.2，按 §3.1 算出 F / C / G / A
3. 情绪动机：焦虑、内疚、羞耻、烦躁、亲近、恐惧
4. 内部言语：值不值、得不得罪、有没有后路
5. 元认知预演：对方会怎么解码、关系会怎么反馈
6. 意图：按 §3.2 选档
7. 编码与补偿：方式按 §3.4，补偿按 §3.3 的 K 档
8. 听者解码 / 反馈
9. 关系重构：修复 / 降级 / 设边界 / 疏远

不得省第 3 步「情绪动机」与第 9 步「重构」。

## 五 模式与步骤


**快速模式（默认）**：步骤 1—6 + 参数记录 + 总结。

**深度模式**：按判据开启，最多 2 个；全开仅限长篇小说主角色、游戏 NPC 核心、冲突推演、用户明确要求。

| 模块 | 开启判据 | 最小产出 |
| --- | --- | --- |
| 思考逻辑 | 需解释「想一套说一套」、内心戏、防御机制 | 评估 → 内部言语 → 元认知 → 防御 → 实践三段论 |
| 行为逻辑 | 对 ≥3 类对象行为不同，或需写权威 / 线上差异 | 对 A / 对 B / 对权威 / 线上各 1 条 + 链 |
| 四层视角 | 冲突涉及规范、羞耻、身份、社会文化压力 | 个体 / 他人 / 大他者 / 社会文化各 1—2 行，跨层 ≥3 层各 1 句 |
| 情景分析 | 需预测一次完整「请求 → 反馈 → 重构」或多轮冲突 | 完整 9 步 + P 档位 + F / C / G / A |

优先级（只开 2 个时）：情景分析 > 四层视角 > 行为逻辑 > 思考逻辑。

**跨层六层名单**（四层视角模块的跨层部分按此写，不得自拟）：**生物—心理—社会—语言—文化—历史**。六层都写，最低通过线为至少 3 层各 1 句。

**操作步骤**：定原型（含标签反例）→ 定冲突 → 分三层 → 建言语库 → 列好恶 → 写拒绝 →（可选深度模块）→ 参数记录 → 自检。

## 六 模板


| 字段 | 必填 | 填充要求 |
| --- | --- | --- |
| 卡头 | 是 | 集合原型声明 + 「每个核心标签必须配反例 / 越界条件」 |
| 0 一句话定位 | 是 | 这是谁、靠什么活、卡在哪 |
| 1 核心定位 | 是 | 年龄 / 身份；标签 1—3 个，每个写「标签：…；反例：当……时，不成立 / 会反向」 |
| 2 性格三层 | 是 | 表层；中层；深层；核心冲突 |
| 3 言语库 | 是 | 对 A；对 B；对 C；口头禅；语码与面子策略 |
| 4 好恶 | 是 | 喜好 / 厌恶 |
| 5 拒绝逻辑 | 是 | 软；硬；特殊；反馈 / 重构（至少一条）；公式见 §3.1、档位见 §3.2 |
| 6 思考逻辑 | 否 | 评估 → 内部言语 → 元认知 → 防御 → 实践三段论 |
| 7 行为逻辑 | 否 | 对 A；对 B；对权威；线上；目标 → 手段 → 行动 → 强化 → 调整 |
| 8 四层与跨层 | 否 | 个体内部；他人；大他者 / 象征秩序；社会文化；跨层 ≥3 层 |
| 9 情景分析 | 否 | 9 步 + P 档位 + F / C / G / A |
| 10 参数记录 | 是 | 12 项 P；6 项 S；F / C / G / A；策略档；K 档 |
| 11 一句话总结 | 是 | 核心循环 + 核心冲突 |

**模式规则**：快速 = 0—5 + 10 + 11；深度按判据加 6—9。

## 七 自检（必过项不过则返工）


| # | 检查项 | 合格判据 | 适用 |
| --- | --- | --- | --- |
| 1 | 核心冲突 | 写出接近—回避 / 自尊 / 面子 / 权力 / 欲望 / 焦虑至少一对，并在 ≥1 情景触发 | 必过 |
| 2 | 三层一致 | 深层能解释表层，中层不打架 | 必过 |
| 3 | 言语分对象 | 对 A / B / C 语码不同，或说明为何相同 | 一般项 |
| 4 | 标签反例 | 每个核心标签有反例，且 ≥1 个在情景中被触发 | 必过 |
| 5 | 拒绝分档 | 软 / 硬 / 特殊各 1 例，或标注「不适用」并说明 | 必过 |
| 6 | 反馈循环 | 至少一条言行 → 听者解码 → 关系重构 | 必过 |
| 7 | 参数档位 | 拒绝相关 r、p、o、w、q_s、q_l、q_r、i、c 及 s_f / s_g / s_d 至少各 1 档；深度模式另填 §2.1 / §2.2 全量 + F / C / G / A | 必过 |
| 8 | 补偿匹配 | 已判 K 档；K ≥ 1 时补偿类型与档位一致（硬拒不超 1 项，特殊拒须为行为补偿） | 必过 |
| 9 | 非临床 | 无诊断、无真实个体、无决定论预测 | 必过 |
| 10 | 思考逻辑完整 | 评估 → 内部言语 → 元认知 → 防御 → 实践三段论 | 开启时必过 |
| 11 | 行为逻辑完整 | 对 A / 对 B / 对权威 / 线上各 1 条 + 完整链 | 开启时必过 |
| 12 | 四层 + 跨层 | 四层各 1—2 行；跨层 ≥3 层各 1 句，层名取 §五 的六层名单 | 开启时必过 |
| 13 | 情景分析 9 步 | 完整 9 步 + P 档位 + F / C / G / A；缺反馈或重构即不过 | 开启时必过 |

**总阈值**：必过项（1、2、4、5、6、7、8、9）与「开启时必过」全部通过；一般项 3 允许不通过，但须在自检里写明理由。

凡判过、填过的，都要给证据或反例，不能只打勾。

## 附：三个术语


- **大他者 / 象征秩序**：社会共享的规范视角，即角色脑中「别人会怎么看」的内化凝视。
- **语码**：同一角色对不同对象切换的语言变体。
- **实践三段论**：以「大前提（规范）— 小前提（情境）— 结论（行动）」展开的实践推理。
