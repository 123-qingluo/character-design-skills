## 八 示例（陈默，26 岁剧本杀 DM）


**快速卡**

- 一句话定位：靠「接得住别人」活着，卡在被需要与被看见之间。
- 核心标签与反例：① 接得住别人｜反例：自己崩的时候消失两天，微信不回。② 把责任往身上揽｜反例：真是别人的错时，一句不解释地走开。③ 台词比真话顺｜反例：真要道歉时会卡住，只能说「那个……你饿不饿」。
- 三层：表层话多、爱造梗、永远给别人递台阶；中层把「让别人舒服」当安全策略；深层怕自己是多余的。冲突：被需要 vs 被看见。
- 言语：对客人上扬、给选项；对朋友损、抢话；对权威过度礼貌。口头禅「要不这样」。语码：DM / 朋友 / 陌生人。
- 好恶：喜欢散场后收牌、被记住名字、便利店关东煮；厌恶「你好冷漠」、被追问「你到底想干嘛」、别人替他付钱。
- 拒绝：软「要不这样，我给你找个更合适的」；硬极少，真硬起来是沉默加起身走；特殊「谁要跟你去」，人已经在门口。
- 参数：P r=3 p=1 o=0 w=0 q_s=1 q_l=+1 q_r=0 i=+1 c=1；S s_f=1 s_g=3 s_d=1 s_n=3 s_def=2；派生 F=1、C=2、G=3、A=1。
- 总结：把所有人的台阶都铺好，除了自己那一级。

**情景推演：凌晨三点半，室友周哲说「你回去吧」**

1. 请求：室友劝他回去睡。
2. 评估：同上参数；F=1、C=2、G=3、A=1。
3. 情绪：羞耻 3 + 亲近 2。
4. 内部言语：「回去就是认了这伤是我害的。」
5. 预演：留下，周哲会说第二遍；回去，他睡不着。
6. 意图：规则 1 命中（r≥2、亲近 2、羞耻 3、s_n=3）→ **特殊拒绝**。
7. 编码：「谁演了，我明天十点才开门，顺路。」（s_def=2 缓冲型，被嘴硬盖住）；补偿 K=2（特殊拒绝固定 2）→ 事后（人不走）+ 关系（把折叠床挪半尺，让过道宽一点）。
8. 反馈：周哲解码为「他嘴硬」，笑了一下，扯到手。
9. 重构：K=2 → 偏修复。周哲发来「粥要皮蛋瘦肉的」。

**对照（同一角色，同一关系，只换请求）**

- 请吃火锅（q_l=+1、i=+2、羞耻 0）：i′=3，A=1 ≤ C=2；规则 1 因羞耻 0 不命中 → **接受**，不填拒绝逻辑，话术「行啊，但我只吃辣的」。
- 改成来借钱（q_l=+1、i=−2、羞耻 0）：i′=0，C=round((1+3+0+1)/4)=**1**、A=round((1+3)/2)=**2**，A ≤ C 不成立 → 落规则 3（G=3）**软拒绝**，K=2。
- 排错提示：**i 从 +1 到 +2 时 i′=clamp(i+2) 恒为 3，A / C 不变**，这两档之间不会翻转结局；真正的开关是规则 1 是否命中（羞耻值）与 A 是否仍 ≤ C。
